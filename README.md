# Задание 0

## Задача 1

### Текст задачи

1. Опишите функцию `nextch` — модуль ввода-вывода. (Примечание: из-за отсутствия анализатора, формирующего таблицу ошибок, создайте таблицу ошибок вручную.)
2. Разработайте набор тестов для тестирования модуля ввода-вывода.
3. Выполните тестирование модуля ввода-вывода.

### Алгоритм решения

В классе `InputReader` реализован метод `NextCh()`, выполняющий посимвольное чтение исходного кода программы на языке Pascal с отслеживанием номеров строк и колонок.

**Алгоритм работы `NextCh()`:**

1. Проверяется достижение конца файла (`IsEof`). Если достигнут конец файла, проверяется корректность завершения строковых констант и комментариев (при наличии незакрытых кавычек или фигурных скобок генерируется ошибка).
2. Обрабатываются символы перевода строки (`\r`, `\n`) с проверкой единообразия стиля переноса строк (CRLF vs LF). При обнаружении их смешивания формируется предупреждение.
3. Рассчитываются номера текущей строки (`_line`) и столбца (`_column`) с учетом символов табуляции.
4. Выполняется диагностика считываемого символа методом `ValidateCurrentCharacter()`:
* Проверка на наличие нулевых байтов (`\0`).
* Проверка на присутствие непечатных управляющих символов (ASCII-коды вне диапазонов обычного текста).
* Отслеживание контекста строк (одинарные кавычки) и комментариев (фигурные скобки).
* Проверка на недопустимые кириллические символы в идентификаторах и коде вне строк/комментариев.
* Контроль превышения максимальной длины строки (255 символов).


5. При обнаружении отклонений запись об ошибке/предупреждении добавляется в таблицу ошибок `Errors`.

# Задание 1

## Задача 1

### Текст задачи

Написать учебный лексический анализатор для стандарта языка Паскаль.
**Исходные данные:**
Файл 1 – программа пользователя на стандарте языка Паскаль (возможно, с ошибками).

**Результат:**
*Первый этап:* Файл 2 – коды символов программы из файла 1 (числовое представление лексем/символов).
*Второй этап:*

* Для целых чисел добавить проверку, не выходит ли число за пределы допустимого диапазона.
* Для идентификаторов выполнять поиск по таблице ключевых слов.

### Алгоритм решения

Лексический анализатор реализован в классе `Lexer`, который запрашивает символы из `InputReader` и формирует поток токенов (`Token`).

**Алгоритм работы:**

1. Игнорируются пробельные символы и комментарии (`SkipWhitespaceAndComments`).
2. В зависимости от текущего символа определяются лексические категории:
* **Идентификаторы и ключевые слова:** Считывается последовательность букв, цифр и подчёркиваний. Для полученного слова выполняется поиск в словаре ключевых слов `Keywords` (`program`, `var`, `const`, `begin`, `end`, `if`, `then`, `else`, `case`, `for`, `to`, `do` и др.). Если совпадение найдено, токену присваивается соответствующий тип ключевого слова, иначе — `Identifier`. Выполняется проверка на превышение максимальной длины идентификатора (63 символа).
* **Числовые литералы (целые числа):** Считывается последовательность цифр. Преобразованием через `long.TryParse` выполняется проверка на вхождение в допустимый диапазон целых чисел (`int.MinValue` ... `int.MaxValue`). При превышении генерируется ошибка переполнения.
* **Символы и операторы:** Распознаются односимвольные и двухсимвольные операторы (`:=`, `<=`, `>=`, `<>`, `:`, `=`, `;`, `,`, `.`, `+`, `-`, `*`, `/`).
* **Неизвестные символы:** Символы, не входящие в алфавит языка Pascal, регистрируются как ошибки с типом `UnknownCharacter`.


3. На первом этапе данные также сохраняются в файл с кодами лексем (`file2_codes.txt`).

# Задание 2

## Задача 1

### Текст задачи

Написать синтаксический анализатор с нейтрализацией синтаксических ошибок для некоторых конструкций стандарта языка Паскаль (Вариант 6: описание переменных простых типов, синтаксический анализ выражения, операторы: условный, выбора, составной, цикла с параметром).

### Алгоритм решения

Синтаксический анализатор реализован методом рекурсивного спуска в классе `Parser` с механизмом нейтрализации синтаксических ошибок.

**Алгоритм работы:**

1. **Структура программы:** Метод `ParseProgram()` проверяет заголовок `program <имя>;`, блок объявлений `var` и составной оператор `begin ... end.`.
2. **Нейтрализация ошибок (`Expect`):** При отсутствии ожидаемого токена в табличную структуру ошибок добавляется запись с указанием строки и колонки, после чего считывание продолжается без критического останова.
3. **Разбор конструкций (Вариант 6):**
* **Объявление переменных (`ParseVarBlock`):** Разбор списков идентификаторов, разделенных запятыми, двоеточия и простых типов данных (`integer`, `boolean`, `real`, `char`).
* **Выражения (`ParseExpression`):** Рекурсивный разбор арифметических и логических выражений с соблюдением приоритета операций (слагаемые, множители, скобки).
* **Условный оператор (`if ... then ... else`):** Проверка условия, разбор ветви `then` и опциональной ветви `else`.
* **Оператор выбора (`case ... of ... end`):** Разбор селектора, меток вариантов, двоеточий и соответствующего им оператора.
* **Цикл с параметром (`for ... := ... to/downto ... do`):** Разбор переменной цикла, начального значения, направления (`to`/`downto`), конечного значения и тела цикла.
* **Составной оператор (`begin ... end`):** Разбор последовательности инструкций, разделенных точкой с запятой.

# Задание 3

## Задача 1

### Текст задачи

Написать синтаксический и семантический анализатор с нейтрализацией синтаксических ошибок для некоторых конструкций стандарта языка Паскаль (Вариант 6: описание переменных простых типов, синтаксический анализ выражения, операторы: условный, выбора, составной, цикла с параметром).

### Алгоритм решения

В Задании 3 синтаксический анализ (из Задания 2) совмещен с семантическим анализом и ведением таблицы символов (`_symbolTable`).

**Алгоритм работы семантического анализа:**

1. **Регистрация переменных:** В процессе разбора секции `var` все объявленные переменные добавляются в таблицу символов `_symbolTable` вместе с их типами данных. При повторном объявлении переменной фиксируется ошибка "Повторное объявление переменной".
2. **Проверка использования переменных:** При встрече идентификатора в выражениях, операторах присваивания, условиях `if`, `case` или `for` выполняется проверка его наличия в `_symbolTable`. Если переменная не была объявлена выше в секции `var`, генерируется семантическая ошибка "Использование необъявленной переменной".
3. **Контроль типов (Семантика):** Проверяется соответствие типов в операторах присваивания и управляющих конструкциях (например, счетчик цикла `for` должен иметь счетный тип).
4. Ошибки синтаксиса и семантики собираются в единый список `Errors` объекта `InputReader` без остановки процесса трансляции.
